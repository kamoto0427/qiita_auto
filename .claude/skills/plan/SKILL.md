# Plan スキル：要件定義 → 詳細設計 → 実装提案

ユーザーの要望 `$ARGUMENTS`（または会話コンテキスト）をもとに、以下の順番で進めてください。

## 手順

1. `$ARGUMENTS` が空の場合は、まず何を作りたいか・背景・完成イメージを AskUserQuestion で確認してください。
2. `/requirements` スキルを実行し、要件定義書を作成してください。
3. ユーザーの承認が得られたら、**designサブエージェントに委任し**、詳細設計書を作成してください。
4. 詳細設計書の承認が得られたら、`/issue-create` スキルの実行を案内してください。
