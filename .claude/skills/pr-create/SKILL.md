---
name: pr-create
description: 変更内容を確認し、プルリクエストを自動作成する。
---

## 手順
1. `git status` で変更ファイルの一覧を確認する
2. `git diff` で変更内容を確認する
3. **readme-updater** サブエージェントを起動して README.md を最新状態に更新する
4. 未コミットの変更がある場合、変更ファイルを個別に確認して以下を実施する：
   - `.env` / `*.pem` / `*secret*` などの機密ファイルが含まれていないことを確認する
   - 問題なければ適切な日本語のコミットメッセージを生成する
   - `git add <ファイル名>` で個別にステージング（`git add .` は使わない）
   - `git commit` でコミット
5. 現在のブランチを確認し、main ブランチの場合は変更内容に応じた `feature/` ブランチ名を生成して切り替える
6. ユーザーに以下の内容を提示して push・PR 作成の承認を求める：
   - ブランチ名
   - コミット内容のサマリー
   - PR タイトル（案）
   - PR 本文（案）
7. 承認されたら以下を実行する：
   - `git push -u origin <ブランチ名>`
   - `gh pr create` でプルリクエストを作成する
     - タイトル：変更内容を要約した日本語タイトル
     - 本文：変更の概要・目的・確認事項を日本語で記載、`Closes #<Issue番号>` を含める

## 注意
- `git add .` は使わない。必ず変更ファイルを個別に指定する
- push・PR 作成はユーザーの承認後にのみ実行する
